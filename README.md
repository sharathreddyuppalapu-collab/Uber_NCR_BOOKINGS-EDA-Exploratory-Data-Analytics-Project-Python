# 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on NCR (Delhi) ride booking data using Python.

The objective of this project is to clean, process, visualize, and analyze ride booking data to uncover meaningful insights, customer behavior patterns, booking trends, and operational analysis.

The project demonstrates practical data analytics skills including:
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Outlier Detection
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Data Visualization
- Insight Generation

---

# 🎯 Objectives

- Analyze NCR (Delhi) ride booking trends
- Understand customer booking behavior
- Detect inconsistencies and missing values
- Identify and handle outliers
- Explore relationships between ride-related variables
- Generate meaningful business insights through EDA
